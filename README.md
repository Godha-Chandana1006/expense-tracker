# Python Expense Tracker 

A simple Python Expense Tracker that helps users record, view, and summarize their daily expenses.

## Features
- Add expenses with amount, category, description, and date.
- View all recorded expenses.
- Calculate total spending.
- Summarize spending by category.
- Save and load expenses using a CSV file.
## Technologies Used
- Python
- CSV file handling
- Google Colab
- Google Drive
## How to Run
- Open the Expense_Tracker.ipynb notebook in Google Colab.
- Connect your Google Drive.
- Run the notebook cells in order.
- Choose an option from the Expense Tracker menu.
- Add, view, and summarize your expenses.
## Data Storage
Expenses are stored in a CSV file in Google Drive so that saved records can be loaded again when the notebook is run.
Note: Your Google Drive must be connected before running the program.
